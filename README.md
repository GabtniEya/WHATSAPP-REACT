# WhatsApp Clone (React + React Bootstrap)

## Installation
```bash
npm install
npm run dev
```
Puis ouvrez http://localhost:5173

## Fonctionnalités
- Liste des discussions, recherche et filtres (Toutes / Non lues / Groupes)
- Fenêtre de conversation avec bulles, heures et coches (envoyé / reçu / lu)
- Envoi de messages avec réponse automatique simulée
- Compteur de messages non lus
- Interface responsive (mobile : liste ↔ conversation)
